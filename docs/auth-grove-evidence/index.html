Behavior and limits

Reduced-motion states change instantly, without sweeping panels or animated coconut movement. Sound starts off; opt-in creates two quiet short notes, and Off stops active notes and suppresses future cues. The decorative system never reads credential contents. All Firebase traffic is replaced by local fixtures.

Chromium desktop/mobile emulation is covered. Real Safari/iOS and third-party password-manager extensions still need manual device review. GitHub Actions was not run for this local-only child.
